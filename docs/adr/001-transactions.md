# 001. Транзакции и идемпотентность

Платёж и первое событие outbox создаются одной транзакцией; репозитории не делают commit. Уникальный ключ в PostgreSQL разрешает гонку параллельных POST. Сервис сравнивает нормализованную сумму и канонический JSON запроса: совпадение возвращает тот же платёж с текущим статусом, различие — 409. Это предотвращает повторное создание при сетевом повторе, но ключ относится ко всему запросу и должен быть уникален для новой операции.
